# Projeto de Monitoramento e Distribuição de EPIs

Protótipo funcional do sistema

Participante: Vitória Beatriz Silva de Carvalho

Objetivo do projeto:
Um projeto de controle de Equipamentos de Proteção Individual (EPIs) visa assegurar que todos os trabalhadores recebam, utilizem e mantenham adequadamente os equipamentos necessários para sua segurança. Esse controle envolve etapas como a identificação dos riscos ocupacionais, seleção dos EPIs adequados, registro detalhado da distribuição e uso dos equipamentos, além da manutenção e substituição periódica conforme a necessidade .
Implementar esse sistema na empresa vai contribui para a prevenção de acidentes, cumprimento das normas regulamentadoras e promoção de um ambiente de trabalho mais seguro e saudável para todos os colaboradores.
